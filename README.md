# lark_alert

[![CI](https://github.com/Ye-Yu-Mo/lark_alert/actions/workflows/ci.yml/badge.svg)](https://github.com/Ye-Yu-Mo/lark_alert/actions/workflows/ci.yml)

生产可用的飞书自定义机器人 Webhook 通知库。核心逻辑使用 Rust 实现，并通过 PyO3/maturin 直接打包为 Python 扩展，Rust 项目和 Python 项目可以共用同一套 API 风格与消息样式。

## 特性

- 支持飞书自定义机器人消息类型：
  - `text` 文本消息
  - `post` 富文本消息
  - `interactive card` 卡片消息
- 统一卡片样式：
  - 不使用 emoji
  - 仅用 header 颜色表达严重程度
  - `info=blue`、`success=green`、`warning=orange`、`error=red`、`critical=carmine`
- 可选飞书签名校验：
  - 配置 `secret` 后自动附加 `timestamp` 和 `sign`
- 生产级网络行为：
  - 请求超时
  - 有限重试 + 指数退避
  - 连接池复用
- 完善的错误类型：
  - URL 校验、HTTP 错误、飞书业务错误、响应解析错误、重试耗尽
- Python 侧通过 `import lark_alert` 直接使用，无需维护第二套 Python 实现

## 安装

### Rust

在 `Cargo.toml` 中加入：

```toml
[dependencies]
lark_alert = "0.1"
```

### Python

从源码构建 wheel：

```bash
pip install maturin
maturin build --release --out dist
pip install dist/lark_alert-*.whl
```

或者使用 `uv` 本地开发安装：

```bash
uv sync --extra dev
uv run maturin develop
```

## Rust 使用

```rust
use lark_alert::{Card, LarkAlert, Severity};

fn main() -> Result<(), lark_alert::LarkAlertError> {
    let alert = LarkAlert::new("https://open.feishu.cn/open-apis/bot/v2/hook/your-hook")?
        .with_secret("your-secret");

    let card = Card::new()
        .severity(Severity::Error)
        .title("Order service down")
        .summary("checkout is failing")
        .service("order-api")
        .environment("prod")
        .timestamp("2026-01-01T00:00:00Z")
        .field("host", "10.0.0.1")
        .details("error rate > 5% for 10 minutes")
        .note("auto-generated by lark_alert")
        .build();

    alert.send_card(&card)?;
    Ok(())
}
```

## Python 使用

```python
from lark_alert import Card, LarkAlert, Severity

alert = LarkAlert(
    "https://open.feishu.cn/open-apis/bot/v2/hook/your-hook",
    secret="your-secret",
    timeout_secs=10,
    max_retries=3,
)

card = (
    Card()
    .severity(Severity.Error)
    .title("磁盘使用率过高")
    .summary("disk / 使用率 92%")
    .service("prometheus")
    .environment("prod")
    .field("host", "10.0.0.1")
    .wide_field("mount", "/")
    .details("持续 10 分钟超过 90% 阈值")
    .note("auto-generated by lark_alert")
)

alert.send_card(card)
```

更多示例见 [`examples/python_basic.py`](examples/python_basic.py)。
