# lark_alert

生产可用的飞书自定义机器人 Webhook 通知库：Rust 核心 + PyO3/maturin Python 绑定。

- 支持 `text`、`post`、`interactive card` 三类飞书自定义机器人消息
- 统一卡片样式：无 emoji，仅用 header 颜色区分级别
  - `info=blue`、`success=green`、`warning=orange`、`error=red`、`critical=carmine`
- 可选飞书签名校验（`timestamp` + `secret`）
- 生产级网络行为：超时、有限重试、指数退避、连接池复用
- Python 侧通过 `import lark_alert` 直接使用，与 Rust API 对齐

## Rust 使用

```rust
use lark_alert::{Card, Severity, LarkAlert};

fn main() -> Result<(), lark_alert::LarkAlertError> {
    let alert = LarkAlert::new("https://open.feishu.cn/open-apis/bot/v2/hook/your-hook")?
        .with_secret("your-secret");

    let card = Card::new()
        .severity(Severity::Error)
        .title("Order service down")
        .summary("checkout is failing")
        .service("order-api")
        .environment("prod")
        .timestamp("2026-01-01T00:00:00Z")
        .details("error rate > 5% for 10 minutes")
        .note("auto-generated by lark_alert")
        .build();

    alert.send_card(&card)?;
    Ok(())
}
```

## Python 使用

```bash
uv sync --extra dev
uv run maturin develop
```

```python
from lark_alert import Card, LarkAlert, Severity

alert = LarkAlert(
    "https://open.feishu.cn/open-apis/bot/v2/hook/your-hook",
    secret="your-secret",
    timeout_secs=10,
    max_retries=3,
)

card = (
    Card()
    .severity(Severity.Error)
    .title("磁盘使用率过高")
    .summary("disk / 使用率 92%")
    .service("prometheus")
    .environment("prod")
    .field("host", "10.0.0.1")
    .note("auto-generated by lark_alert")
)

alert.send_card(card)
```

更多示例见 [`examples/python_basic.py`](examples/python_basic.py)。
